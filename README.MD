# 📊 HabitFlow (Habit Tracker)

HabitFlow is a full‑stack habit tracking web application built with **Next.js** (frontend) and **FastAPI** (backend). It helps users create, manage, and analyze their daily habits with a clean dashboard, weekly streaks, and analytics.

---

## 🚀 Features
- ✅ User authentication (signup/login with JWT)
- 📅 Add, edit, delete habits
- ⏰ Track habit completion with timestamps
- 📊 Analytics dashboard (completion trends, streaks, heatmaps)
- 📈 Weekly progress view
- 🌙 Dark theme UI inspired by GitHub styling

---

## 🛠 Tech Stack
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** FastAPI, Python
- **Database:** MongoDB (via Flask‑PyMongo)
- **Auth:** JWT tokens
- **Deployment:** GitHub + (Render/Heroku/Netlify optional)

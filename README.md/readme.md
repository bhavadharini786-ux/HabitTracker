# Habit Tracker 🚀

A full-stack **Habit Tracker Web Application** that helps users build consistency, track daily habits, and visualize progress through analytics.

---

## ✨ Features

* 🔐 User Authentication (Signup & Login)
* ✅ Add, update, and delete habits
* 📅 Daily habit tracking
* 📊 Weekly analytics dashboard
* 📈 Line chart for habit trends
* 🥧 Pie chart for completion overview
* 🔥 GitHub-style heatmap for consistency tracking
* 💡 Smart habit improvement suggestions

---

## 🛠️ Tech Stack

**Frontend**

* HTML, CSS, JavaScript
* Chart.js

**Backend**

* Python (Flask)

**Database**

* MongoDB

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/habit-tracker.git
cd habit-tracker
```

### 2. Create virtual environment

```
python -m venv venv
```

### 3. Activate virtual environment

**Windows**

```
venv\Scripts\activate
```

**Mac/Linux**

```
source venv/bin/activate
```

### 4. Install dependencies

```
pip install -r requirements.txt
```

### 5. Set environment variables

Create a `.env` file and add:

```
SECRET_KEY=your_secret_key
MONGO_URI=your_mongodb_connection_string
```

---

### 6. Run the application

```
python run.py
```

Open in browser:

```
http://127.0.0.1:5000
```
